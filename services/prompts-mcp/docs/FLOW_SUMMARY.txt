5 CHAOS POINTS (Where Things Could Break at Scale)
───────────────────────────────────────────────────────────────────────────────

1. GOROUTINE SPAWNING  🔴 HIGH RISK
   • Current: 1 request → spawn 1 goroutine
   • At 1000 req/s: 1000 goroutines/sec
   • Risk: Orphaned goroutines if timeout (no cleanup)
   • Fix: Worker pool (100 max) + context cancellation
   • Gain: 40% resource stability

2. JSONL APPEND BOTTLENECK  🟡 MEDIUM RISK
   • Current: feedback.jsonl append (O(append))
   • At 100+ writes/sec: File I/O becomes bottleneck
   • Risk: Unknown perf past 100 writes/sec
   • Fix: SQLite migration (Phase 6.2)
   • Gain: 50% feedback performance improvement

3. MEMORY ALLOCATIONS  🟡 MEDIUM RISK
   • Current: Deep copy on every GetIndex (cached)
   • At high request rate: Unknown GC pressure
   • Risk: GC pauses could spike
   • Fix: Profile + optimize heap usage
   • Gain: Predictable latency p99

4. LOGGER LOCK CONTENTION  🟡 MEDIUM RISK
   • Current: All errors serialize through one lock
   • At 1000 req/s + 10% errors: 100 goroutines blocking
   • Risk: Error-path latency degrades
   • Fix: Async logging buffer
   • Gain: 60% error-path latency improvement

5. LARGE PAYLOAD PARSING  🟡 MEDIUM RISK
   • Current: 10MB JSON parse time unknown
   • Risk: Could take 1-2s (environmental)
   • Fix: Stream decoder for large imports
   • Gain: Predictable import latency
