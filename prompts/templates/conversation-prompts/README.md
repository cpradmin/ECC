Guide Eve in creating clear, engaging explanations and maintaining effective dialogue with users.

## Template

Use the YAML schema from `../SCHEMA.md` and include:

1. **Trigger** — e.g., "when explaining a complex concept"
2. **Purpose** — What communication goal are we achieving?
3. **Examples** — Before/after for explanation clarity
4. **Confidence Evolution** — How to test this prompt's effectiveness

See `../router-prompts/00-domain-classifier.yaml` for a complete example.
