## Template

Use the YAML schema from `../SCHEMA.md` and include:

1. **Trigger** — e.g., "when processing a data pipeline"
2. **Purpose** — What task or pattern are we enabling?
3. **Code Examples** — Best practices and libraries
4. **Confidence Evolution** — How to test this prompt's effectiveness

See `../router-prompts/00-domain-classifier.yaml` for a complete example.
