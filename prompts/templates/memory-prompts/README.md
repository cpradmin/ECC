## Template

Use the YAML schema from `../SCHEMA.md` and include:

1. **Trigger** — e.g., "when retrieving context for a complex task"
2. **Purpose** — What knowledge pattern are we capturing?
3. **Examples** — Query patterns and expected results
4. **Confidence Evolution** — How to validate memory quality and usefulness

See `../router-prompts/00-domain-classifier.yaml` for a complete example.
