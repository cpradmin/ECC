# IaC Prompts Template

Terraform/Ansible specialist — infrastructure as code, cloud deployment, configuration management.

## Purpose

Guide infrastructure design and automation: idempotency, modularity, safety, observability.

## Example Prompts

(To be added in Phase 2+)

- Terraform module structure and composition
- State isolation and backend configuration
- Ansible playbook idempotency patterns
- Safe rollback and drift detection strategies
- Secret management and security hardening

## Template

Use the YAML schema from `../SCHEMA.md` and include:

1. **Trigger** — e.g., "when designing a cloud deployment"
2. **Purpose** — What infrastructure pattern are we implementing?
3. **Examples** — HCL/YAML snippets and configurations
4. **Confidence Evolution** — How to validate this prompt in production deployments

See `../router-prompts/00-domain-classifier.yaml` for a complete example.
